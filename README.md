# Antonella Andreini — Portfolio

Personal portfolio for Antonella Andreini, a Software Engineer and Product Engineer based in Argentina.

The site highlights:

- Full-stack product engineering experience
- AI-assisted engineering and open-source repository work
- Testing, CI/CD, and DevOps experience
- Personal projects and technical writing

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- React Router
- MDX

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Deployment

The repository includes a `netlify.toml` configuration for deployment on Netlify.
